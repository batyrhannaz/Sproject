# 🎓 Школьный портал с библиотекой

Полнофункциональная система, объединяющая электронный дневник/журнал (по аналогии с Э-Күндөлүк), персональные кабинеты 5 ролей и школьную библиотеку, созданную с нуля.

---

## ⚡ Быстрый запуск одной командой

Проект уже подготовлен, миграции применены, демо-данные сгенерированы:

```bash
python manage.py runserver
```

После запуска перейдите в браузере по адресу: **`http://127.0.0.1:8000/`**

Для повторного сброса и генерации демонстрационных данных:
```bash
python manage.py seed_data
```

Запуск всех автотестов системы:
```bash
python manage.py test
```

## 🧩 Реализованные функции по техническому заданию

### 1. Единый вход и роли
- Экран входа с выбором роли (Ученик, Родитель, Учитель, Библиотекарь, Директор).
- Сброс пароля через привязанный Gmail (ссылка генерируется и выводится в консоль терминала в dev-режиме, либо отправляется по SMTP при указании настроек в `.env`).
- Каждая роль попадает в свой кабинет и изолирована от чужих разделов (проверено тестами `school/tests.py`).

### 2. Общие функции кабинета
- **Боковое меню:** светлая карточка с фото/инициалами профиля, живой поиск по пунктам меню, плавное сворачивание до иконок с сохранением состояния в `localStorage`. У каждой роли персональное меню.
- **Кнопка «Выйти»:** всегда видна на всех страницах (в шапке topbar и внизу бокового меню в свёрнутом и развёрнутом виде).
- **Страница «Настройки»:** выбор языка (RU / KG / EN), размера шрифта (компактный / стандартный / крупный), загрузка фото профиля, привязка Gmail, смена пароля и экспорт персональных данных в JSON.
- **Адаптивный дизайн:** полноценная работа на смартфонах и планшетах (выезжающее мобильное меню, адаптивные таблицы и карточки).

### 3. Учебный блок
- **Электронный журнал класса:** выбор класса, предмета и даты, матрица учеников с историей оценок, выставление оценок (1–5) с комментариями и отметками посещаемости (Был, Н, Б, УП).
- **Четвертные оценки:** сводная ведомость с расчётом среднего балла и выставлением четвертных/годовых оценок.
- **Табель успеваемости:** доступен в кабинете родителя и ученика.
- **Домашние задания:** публикация учителем с прикреплением файлов и дедлайнами; отображение у ученика и родителя.
- **Расписание и звонки:** сетка занятий по дням недели для каждого класса, расписание звонков для 1-й и 2-й смен.
- **Сообщения и объявления:** внутренний почтовый модуль между родителями, учителями, библиотекарем и директором; общешкольные и важные объявления.
- **Импорт пользователей:** массовая загрузка учеников и учителей из файлов Excel (`.xlsx`) и CSV.
- **Публичные страницы:** Главная, Новости, Расписание звонков, Контакты и приёмная.

### 4. Школьная библиотека (с нуля)
- **Каталог и поиск:** поиск по названию, автору, ISBN; фильтрация по жанру, классу (1–11), языку и наличию.
- **Карточка книги:** обложка, аннотация, язык, год, ISBN, количество экземпляров и статус (В наличии, Выдана, Забронирована).
- **Разделы «Новинки» и «Популярное»:** автоматический отбор по новизне и частоте выдач.
- **Цикл «Бронь → Выдача → Возврат»:**
  1. Ученик бронирует книгу в каталоге (бронь ставится на 3 дня).
  2. Библиотекарь подтверждает бронь и оформляет выдачу (срок возврата ставится автоматически: +14 дней).
  3. При возврате библиотекарь фиксирует физическое состояние книги (Отличное, Хорошее, Удовлетворительное, Ветхое), экземпляр снова становится доступен.
- **Контроль задолженностей и должники:**
  - Просроченные книги подсвечиваются ярким красным бейджем.
  - Ученик и родитель видят тревожное уведомление прямо в шапке и в личном кабинете.
  - **Правило ТЗ:** читатель с просроченной книгой блокируется от новых бронирований.
  - Лимит: максимум 3 книги на руках у читателя.
- **Кабинет библиотекаря:**
  - Быстрая выдача и приём возвратов.
  - Подтверждение и отклонение онлайн-броней.
  - Реестр должников с контактами и кнопкой напоминания.
  - Управление книгами, добавление экземпляров и списание ветхих.
  - Отчёты по популярным книгам, активным читателям и состоянию фонда.
  - Выгрузка всего отчёта и текущих выдач в **Excel (`.xlsx`)**.
  - Массовый импорт каталога книг из Excel/CSV.
  - Настройка параметров библиотеки (срок выдачи, лимит книг, срок брони).

## 🏗️ Архитектура проекта

- `accounts/` — модель пользователя `User`, роли `Role`, связь `ParentStudentRelation`, настройки, авторизация, сброс пароля, экспорт.
- `school/` — классы `SchoolClass`, предметы `Subject`, назначения учителей, профили, расписание `Timetable`, звонки `BellSchedule`, оценки `Grade`, четвертные `QuarterGrade`, посещаемость `Attendance`, домашние задания `Homework`, объявления `Announcement`, личные сообщения `Message`, новости `SchoolNews`, публичные страницы.
- `library/` — правила `LibrarySettings`, жанры `Genre`, книги `Book`, экземпляры `BookCopy`, брони `Reservation`, выдачи `BorrowRecord`, рекомендации `BookRecommendation`, отчёты и экспорт в Excel.
- `templates/` — HTML-шаблоны со светлым адаптивным интерфейсом.
- `static/` — стили CSS, JS скрипты управления меню, модальными окнами и поиском.
